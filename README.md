# VOO / QQQM 投资记录工具

一个面向个人投资者的本地投资账本，使用 Python、SQLite 和中文浏览器界面，记录 VOO 与 QQQM 的真实交易、分红和投资计划。

支持两只 ETF 的独立 VA（Value Averaging，价值平均法）计划：每月确定并锁定预算，再在月内分批执行。行情更新、市场晨报和历史回测分别提供独立入口。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 真实账本 | 记录入金、出金、买入、卖出、分红及税费，支持编辑与 CSV 导出 |
| 持仓与收益 | 汇总现金、股数、持仓成本、平均成本、参考市值及已实现／未实现盈亏 |
| 投资日历 | 展示滚动 12 个月目标、锁定预算、实际投入和执行进度 |
| 行情与收益更新 | 下载两只 ETF 的行情，更新估算用价格并重新计算收益 |
| 美股晨报 | 按需联网生成市场信息、新闻和走势图，并导出中文 HTML |
| 历史回测 | 对照独立 VA 与固定金额 DCA，研究结果与真实账本分离 |
| 档案与维护 | Obsidian 同步、拆股人工核对、健康检查、完整备份与旧报告回收 |

程序只记录和分析，不自动下单，不连接券商交易接口。

## 快速开始

### 运行环境

- macOS，已在 Python 3.14 环境验证。
- 行情更新与晨报生成需要网络；本地账本使用 SQLite。
- 依赖列表见 `程序文件/requirements.txt`。

### 安装

下载源码并解压，或克隆仓库。在终端进入项目根目录后执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r 程序文件/requirements.txt
chmod +x 管理投资记录.command
./管理投资记录.command
```

启动器首次运行时会从 `config.example.json` 创建本地 `config.json`，并初始化空数据库。以后可以直接双击 **管理投资记录.command** 打开页面。

也可以在项目根目录通过终端启动：

```sh
.venv/bin/python -B 程序文件/investment_gui.py --config 程序文件/config.json
```

本地服务监听 `127.0.0.1`，启动时生成随机会话令牌。源码包不附带真实交易或行情，首次使用可点击 **更新行情与收益** 下载行情；录入账本无需先下载行情。

## 使用流程

1. **记录现金与交易**：填写实际到账、成交或分红数据。买卖金额不含交易费用；分红填写税前金额和税费，净到账自动计算。
2. **查看收益**：点击顶部“更新行情与收益”。总览显示行情日期、持仓估价日期、价格来源及更新结果。
3. **确定当月预算**：在预算日更新行情，到投资日历预览并锁定两只 ETF 各自的预算。
4. **月内分批执行**：交易完成后录入真实成交，对应预算的已投入金额和完成度自动更新。
5. **按需研究市场**：生成晨报查看市场信息，或在设置页运行历史回测。
6. **维护档案**：定期检查账本、导出记录或生成完整备份。

## 独立 VA 计划

两只 ETF 分别维护目标价值路径，互不抵消缺口。以下是模板中的示例参数，可在设置页修改：

| 参数 | VOO | QQQM |
| --- | ---: | ---: |
| 首月目标价值 | 500 USD | 300 USD |
| 每月目标增量 | 500 USD | 300 USD |

因此，第 2 个月目标分别为 1,000 / 600 USD，第 3 个月为 1,500 / 900 USD。**目标价值不是每月固定投入金额**；当月预算取决于目标与预算日前持仓参考市值之间的缺口。

```text
当月目标价值 = 首月目标价值 + 月份序号 × 每月目标增量
预算参考市值 = 预算日前持仓股数 × 预算日前最近完整交易日收盘价
锁定预算 = max(0, 当月目标价值 - 预算参考市值)
剩余预算 = max(0, 锁定预算 - 归属当月的实际买入金额)
```

月份序号从 0 开始。模板预算日为每月 2 日；使用前应修改计划起始月份和参数。预算确认后不会随月内行情自动改变。历史回测的执行日是独立研究参数，不是实盘交易截止日。

当前计划为买入型 VA：持仓参考市值超过目标时，预算为零，不自动产生卖出指令。

## 行情与收益口径

- **实盘估值及预算**使用实际收盘价；**历史回测及收益走势**使用复权价。两套行情分别保存并校验。
- 行情为最近完整交易日的收盘数据，不是盘中实时报价。周末和休市期间，行情日期可能早于当天。
- 日期更晚的手动参考报价会保留。查看收益时，应同时核对持仓估价日期和价格来源。
- 未实现盈亏＝持仓参考市值－当前持仓成本。
- 累计已实现盈亏＝卖出盈亏＋净分红；累计总盈亏再加未实现盈亏并扣除入金／出金美元费用。
- 卖出盈亏采用移动平均成本，可能与券商按税务批次计算的结果不同。
- 账本统一采用 USD，不计入港币汇率变化或港币费用的损益。
- 盈亏按红亏绿盈显示；VA 预算／缺口的红色表示超过月度基准，绿色表示基准以内，含义与盈亏不同。

## Obsidian 同步

同步默认关闭。启用前，在本地 `程序文件/config.json` 中设置 Vault 根目录、投资档案子目录及 `obsidian_sync_enabled`。

工具在主文档中只更新固定生成标记区块；其他手写内容保留。逐笔记录使用工具生成的笔记，不覆盖同名手写笔记。建议首次同步前备份 Vault。

## 数据存储与备份

| 路径 | 内容 |
| --- | --- |
| `程序文件/config.json` | 本机配置与个人路径 |
| `程序文件/data/investments.sqlite3` | 真实账本、报价、预算及修订记录 |
| `程序文件/data/` | 行情快照、晨报数据和更新状态 |
| `程序文件/reports/` | 中文投资报告与晨报 HTML |
| `程序文件/va_backtest_results/` | 历史回测结果 |
| `程序文件/data/backups/` | 自动数据库备份与手动完整备份 |

设置页可生成完整备份，保留最近三份；每日首次修改数据库前另有自动备份，默认保留最近 30 份。CSV 用于阅读和交换，不替代完整账本备份。

恢复前关闭工具，解压到新目录并核对账户后再替换原目录。跨电脑迁移时重建 Python 虚拟环境，并调整个人路径。

## 发布与隐私

本源码包不包含真实账本、个人配置、行情、报告、虚拟环境或历史备份。`.gitignore` 排除了这些运行时文件。

通过 Git 上传时不要强制提交忽略文件。通过 GitHub 网页上传时，网页不会替你应用本地 `.gitignore`；请上传干净源码包的内容，不要上传运行后产生的数据目录。完整备份包含私人账本，应私人保存。
